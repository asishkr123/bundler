2. Decisions and precise contracts

Inputs and identity

  • Use Node 24 or newer with --experimental-vm-modules. Accept one or more existing local .js/.mjs entries and relative static import/export ... from dependencies. Side-effect imports count. Dynamic import() is omitted from this graph even when literal; the demo labels its request outside the static graph.
  • Reject bare, absolute, query/hash, and unsupported extension specifiers with the importer and exact specifier in the diagnostic. Resolve ./util in this order: util.js, util.mjs, util/index.js, util/index.mjs. Explicit .js/.mjs specifiers resolve exactly. Directory imports resolve only through those index candidates. Valid ../ imports are accepted when the final real file stays inside the real project root.
  • Canonical identity is the resolved real file path, converted to a project-relative forward-slash ID after checking containment within the root's real path. In-root symlink aliases collapse to one node and use the target's ID. An outside symlink is rejected. entries preserves argument order, including duplicate canonical IDs when two entry arguments name the same file; modules contains that file once.
  • One import edge is emitted per unique specifier in the order of its first static occurrence in source. Edges retain the original specifier and canonical target. Use SourceTextModule.moduleRequests and an explicit seen-specifier set; reject import attributes or phases beyond ordinary JS evaluation because Task 1 does not model them. Node 24.14 currently collapses identical requests, but the explicit set preserves our schema policy if VM behavior changes. Strings/comments do not create edges. Unsupported syntax that Node cannot parse fails with the source ID.
  • After following an in-root symlink, the real target must itself end in .js or .mjs. A .js alias to data.txt is rejected with importer/specifier context. The fixed demo server rejects symlinked public files, so browser URL matching is promised only for the shipped, no-symlink vanilla demo; inspect may still canonicalize in-root symlinks.

Graph report

Keep schemaVersion: 1, root: ".", entries, modules, and why. Each module has id, UTF-8 bytes, and imports with specifier/target. Sort modules and why keys by Unicode code-unit order, without locale dependence. Breadth-first search over entries in declared order and edges in first-occurrence order chooses one shortest path. why is an inclusion explanation, not execution order, request initiator, or the only path. JSON contains no absolute paths, timestamps, or machine-specific data.

CLI, HTTP, and observation

  • inspect <entry> [more entries] accepts arbitrary supported local entries. serve <entry> accepts only the documented examples/vanilla/main.js, since its HTTP allowlist and HTML always run that fixed demo. Another serve entry is a usage error (exit 2), rather than a misleading graph about a different app. Graph, filesystem, and server startup failures exit 1; success exits 0. Diagnostics go to stderr and are command-specific. Build the entire graph before creating a new report. Write to a unique temporary file in dist/, then rename it over graph.json. On inspect failure, an earlier report may remain and must be identified as stale. No partial report is presented as current.
  • The server binds 127.0.0.1:4173 and serves only / (demo HTML), /__graph, /src/browser-inspector.mjs, and five demo asset routes under /examples/vanilla/ (main, message, suffix, feature, CSS). Only GET/HEAD are allowed. Successful responses have appropriate MIME type and Cache-Control: no-store. Unknown paths return 404, malformed paths 400, and symlink escape or non-public file attempts return 403/404 without file bytes. /__graph serves the graph built at startup; restart the demo after source changes.
  • The browser table uses Resource Timing entries as observations. Static JS rows show the graph's inclusion chain. CSS identifies the HTML stylesheet link, inspector JS identifies the HTML script tag, and feature.js says “Observed feature request; demo button contains a dynamic import; outside Task 1 static graph.” The URL alone does not establish that a click happened; B1/B2 establish before/after separately. URL-to-ID matching covers the shipped no-symlink demo only. A zero or missing transferSize displays “unavailable (zero or missing; cache possible)”. Browser API absence and graph fetch failure show explicit fallback/error text. DOM text uses textContent only.

Resolution and root containment · src/graph.mjs

import { realpath, stat } from 'node:fs/promises';
import path from 'node:path';

async function createResolver(root) {
  const rootReal = await realpath(root);
  function assertWithinRoot(realFile, context) {
    const rel = path.relative(rootReal, realFile);
    if (rel === '..' || rel.startsWith('..' + path.sep) || path.isAbsolute(rel)) {
      throw new Error(context + ' escapes the project root: ' + realFile);
    }
  }
  function idOf(realFile) {
    return path.relative(rootReal, realFile).split(path.sep).join('/');
  }
  async function resolveEntry(entry) {
    const extension = path.extname(entry);
    if (extension !== '.js' && extension !== '.mjs') {
      throw new Error('Entry must be .js or .mjs: ' + JSON.stringify(entry));
    }
    const requested = path.resolve(rootReal, entry);
    let realFile;
    try { realFile = await realpath(requested); }
    catch (error) {
      if (error.code === 'ENOENT' || error.code === 'ENOTDIR') {
        throw new Error('Cannot resolve entry ' + JSON.stringify(entry), { cause: error });
      }
      throw new Error('Cannot access entry ' + JSON.stringify(entry) + ': ' + error.message,
        { cause: error });
    }
    assertWithinRoot(realFile, 'Entry ' + JSON.stringify(entry));
    if (!['.js', '.mjs'].includes(path.extname(realFile))) {
      throw new Error('Entry resolves to non-JS file: ' + JSON.stringify(entry));
    }
    try {
      if (!(await stat(realFile)).isFile()) {
        throw new Error('Entry is not a file: ' + JSON.stringify(entry));
      }
    } catch (error) {
      if (error.code) throw new Error('Cannot access entry ' + JSON.stringify(entry) +
        ': ' + error.message, { cause: error });
      throw error;
    }
    return realFile;
  }
  async function resolveLocal(importerReal, specifier) {
    if (!specifier.startsWith('./') && !specifier.startsWith('../')) {
      throw new Error('Unsupported import ' + JSON.stringify(specifier) + ' in ' + idOf(importerReal));
    }
    if (specifier.includes('?') || specifier.includes('#')) {
      throw new Error('Unsupported query/hash import ' + JSON.stringify(specifier) + ' in ' + idOf(importerReal));
    }
    const base = path.resolve(path.dirname(importerReal), specifier);
    const ext = path.extname(base);
    if (ext && ext !== '.js' && ext !== '.mjs') {
      throw new Error('Unsupported module extension ' + JSON.stringify(specifier) +
        ' in ' + idOf(importerReal));
    }
    const candidates = ext ? [base] : [base + '.js', base + '.mjs',
      path.join(base, 'index.js'), path.join(base, 'index.mjs')];
    for (const candidate of candidates) {
      try {
        if (!(await stat(candidate)).isFile()) continue;
        const realFile = await realpath(candidate);
        assertWithinRoot(realFile, 'Import ' + JSON.stringify(specifier) +
          ' from ' + idOf(importerReal));
        if (!['.js', '.mjs'].includes(path.extname(realFile))) {
          throw new Error('Import ' + JSON.stringify(specifier) + ' from ' +
            idOf(importerReal) + ' resolves to a non-JS file');
        }
        return realFile;
      } catch (error) {
        if (error.code === 'ENOENT' || error.code === 'ENOTDIR') continue;
        if (error.code) throw new Error('Cannot access ' + JSON.stringify(specifier) +
          ' from ' + idOf(importerReal) + ': ' + error.message, { cause: error });
        throw error;
      }
    }
    throw new Error('Cannot resolve ' + JSON.stringify(specifier) + ' from ' + idOf(importerReal));
  }
  return { rootReal, idOf, resolveEntry, resolveLocal };
}

Input/output examples: with root /project, resolveLocal("/project/src/main.js", "../shared.js") returns the real /project/shared.js. If /project/src/alias.js points to /project/shared.js, both resolve to ID shared.js. An outside target throws with importer/specifier context; alias.js pointing to data.txt is rejected as non-JS. Traversal and shortest explanations · src/graph.mjs

import { readFile } from 'node:fs/promises';
import { SourceTextModule } from 'node:vm';

function computeWhy(entries, nodes) {
  const found = new Map();
  const queue = entries.map(id => ({ id, chain: [id] }));
  for (let head = 0; head < queue.length; head++) {
    const { id, chain } = queue[head];
    if (found.has(id)) continue;
    found.set(id, chain);
    for (const edge of nodes.get(id).imports) {
      queue.push({ id: edge.target, chain: [...chain, edge.target] });
    }
  }
  return found;
}

export async function buildGraph(entryPaths, root = process.cwd()) {
  if (!Array.isArray(entryPaths) || entryPaths.length === 0) {
    throw new Error('At least one entry is required');
  }
  const { idOf, resolveEntry, resolveLocal } = await createResolver(root);
  const nodes = new Map();
  async function visit(realFile) {
    const id = idOf(realFile);
    if (nodes.has(id)) return;
    const source = await readFile(realFile, 'utf8');
    let parsed;
    try { parsed = new SourceTextModule(source, { identifier: id }); }
    catch (error) { throw new Error('Cannot parse ' + id + ': ' + error.message, { cause: error }); }
    const node = { id, bytes: Buffer.byteLength(source, 'utf8'), imports: [] };
    nodes.set(id, node);
    const seenSpecifiers = new Set();
    for (const request of parsed.moduleRequests) {
      if (request.phase !== 'evaluation' || Object.keys(request.attributes).length) {
        throw new Error('Unsupported import attributes or phase ' +
          JSON.stringify(request.specifier) + ' in ' + id);
      }
      const specifier = request.specifier;
      if (seenSpecifiers.has(specifier)) continue;
      seenSpecifiers.add(specifier);
      const targetReal = await resolveLocal(realFile, specifier);
      node.imports.push({ specifier, target: idOf(targetReal) });
      await visit(targetReal);
    }
  }
  const entries = [];
  for (const entryPath of entryPaths) {
    const realFile = await resolveEntry(entryPath);
    entries.push(idOf(realFile));
    await visit(realFile);
  }
  const paths = computeWhy(entries, nodes);
  const ordinal = (a, b) => a < b ? -1 : a > b ? 1 : 0;
  const modules = [...nodes.values()].sort((a, b) => ordinal(a.id, b.id));
  const why = Object.fromEntries(modules.map(module => [module.id, paths.get(module.id)]));
  return { schemaVersion: 1, root: '.', entries, modules, why };
}

Input/output examples: buildGraph(["examples/vanilla/main.js"], root) returns the schema-v1 object shown above; feature.js is absent because import() is not a static dependency. For a diamond where a.js imports left.js before right.js and both import shared.js, why["shared.js"] is ["a.js","left.js","shared.js"]. Marking the node before recursion ends cycles. Breadth-first queue order gives shortest paths and tie order; sorting only affects serialization.

import { readFile, realpath, stat } from 'node:fs/promises';
import path from 'node:path';

const contentTypes = new Map([
  ['.html', 'text/html; charset=utf-8'],
  ['.js', 'text/javascript; charset=utf-8'],
  ['.mjs', 'text/javascript; charset=utf-8'],
  ['.css', 'text/css; charset=utf-8']
]);
const publicFiles = new Map([
  ['/', 'examples/vanilla/index.html'],
  ['/src/browser-inspector.mjs', 'src/browser-inspector.mjs'],
  ['/examples/vanilla/main.js', 'examples/vanilla/main.js'],
  ['/examples/vanilla/message.js', 'examples/vanilla/message.js'],
  ['/examples/vanilla/suffix.js', 'examples/vanilla/suffix.js'],
  ['/examples/vanilla/feature.js', 'examples/vanilla/feature.js'],
  ['/examples/vanilla/style.css', 'examples/vanilla/style.css']
]);
function reply(status, body, contentType = 'text/plain; charset=utf-8') {
  return {
    status,
    headers: { 'content-type': contentType, 'cache-control': 'no-store' },
    body: Buffer.isBuffer(body) ? body : Buffer.from(body)
  };
}
function jsonReply(graph) {
  return reply(200, JSON.stringify(graph), 'application/json; charset=utf-8');
}
function fileReply(file, body) {
  return reply(200, body, contentTypes.get(path.extname(file)));
}
export async function routeRequest(rawUrl, method, { rootReal, graph }) {
  if (method !== 'GET' && method !== 'HEAD') return reply(405, 'Method not allowed');
  let pathname;
  try { pathname = decodeURIComponent(new URL(rawUrl, 'http://127.0.0.1').pathname); }
  catch { return reply(400, 'Bad request'); }
  if (pathname === '/__graph') return jsonReply(graph);
  const relative = publicFiles.get(pathname);
  if (!relative) return reply(404, 'Not found');
  const expected = path.resolve(rootReal, relative);
  try {
    const realFile = await realpath(expected);
    if (realFile !== expected) return reply(403, 'Forbidden');
    if (!(await stat(realFile)).isFile()) return reply(404, 'Not found');
    return fileReply(realFile, await readFile(realFile));
  } catch (error) {
    if (error.code === 'ENOENT' || error.code === 'ENOTDIR') return reply(404, 'Not found');
    return reply(500, 'Internal server error');
  }
}
export function createRequestHandler(context) {
  return async (request, response) => {
    try {
      const result = await routeRequest(request.url || '/', request.method || 'GET', context);
      response.writeHead(result.status, result.headers);
      response.end(request.method === 'HEAD' ? undefined : result.body);
    } catch {
      response.writeHead(500, { 'content-type': 'text/plain; charset=utf-8',
        'cache-control': 'no-store' });
      response.end('Internal server error');
    }
  };
}

Input/output examples: routeRequest("/__graph","GET",context) returns 200, JSON MIME, no-store, and the startup graph. routeRequest("/examples/vanilla/style.css","GET",context) returns 200 with CSS MIME and the stylesheet bytes. routeRequest("/package.json","GET",context) returns 404 with no file bytes. An encoded traversal path returns 404; a public path that becomes a symlink returns 403. The HTTP adapter sends headers/body and omits the body for HEAD. The allowlist and canonical-path equality protect different concerns: unlisted files and symlink substitution.

async function initInspector() {
  const panel = document.querySelector('#module-atlas');
  let graph;
  try {
    const response = await fetch('/__graph', { cache: 'no-store' });
    if (!response.ok) throw new Error('Graph request returned ' + response.status);
    graph = await response.json();
    if (graph.schemaVersion !== 1) throw new Error('Unsupported graph schema');
  } catch (error) {
    panel.textContent = 'Graph explanation unavailable: ' + error.message;
    return;
  }
  const moduleByPath = new Map(graph.modules.map(module => ['/' + module.id, module]));
  let liveUpdates = false;
  function reasonFor(pathname) {
    const module = moduleByPath.get(pathname);
    if (module) return 'Static inclusion: ' + graph.why[module.id].join(' → ');
    if (pathname === '/examples/vanilla/style.css') return 'HTML stylesheet link; outside JS graph';
    if (pathname === '/src/browser-inspector.mjs') return 'HTML module script; outside app graph';
    if (pathname === '/examples/vanilla/feature.js') {
      return 'Observed feature request; demo button contains a dynamic import; outside Task 1 static graph';
    }
    return 'Observed request; outside Task 1 static graph';
  }
  function addCell(row, value) {
    const cell = document.createElement('td');
    cell.textContent = String(value);
    row.append(cell);
  }
  function render() {
    const resources = performance.getEntriesByType('resource')
      .filter(item => /\.(?:js|mjs|css)(?:[?#]|$)/.test(item.name))
      .sort((a, b) => a.startTime - b.startTime);
    panel.replaceChildren();
    const heading = document.createElement('h2');
    heading.textContent = graph.modules.length + ' static modules; ' +
      resources.length + ' observed resources';
    panel.append(heading);
    const note = document.createElement('p');
    note.textContent = 'Static paths explain inclusion. Timings are browser observations, not execution order.';
    panel.append(note);
    if (!liveUpdates) {
      const refresh = document.createElement('button');
      refresh.textContent = 'Refresh observations';
      refresh.addEventListener('click', render);
      panel.append('Live timing updates unavailable. ', refresh);
    }
    const table = document.createElement('table');
    const header = document.createElement('tr');
    for (const label of ['Resource', 'Start (ms)', 'Transfer (bytes)', 'Explanation']) {
      const cell = document.createElement('th');
      cell.textContent = label;
      header.append(cell);
    }
    table.append(header);
    for (const item of resources) {
      const row = document.createElement('tr');
      const pathname = new URL(item.name).pathname;
      const start = Number.isFinite(item.startTime) ? item.startTime.toFixed(1) : 'Unavailable';
      const size = Number.isFinite(item.transferSize) && item.transferSize > 0
        ? String(item.transferSize)
        : 'Unavailable (zero or missing; cache possible)';
      for (const value of [pathname, start, size, reasonFor(pathname)]) addCell(row, value);
      table.append(row);
    }
    panel.append(table);
  }
  try {
    if (typeof PerformanceObserver === 'function') {
      const observer = new PerformanceObserver(render);
      observer.observe({ type: 'resource', buffered: true });
      liveUpdates = true;
    }
  } catch { liveUpdates = false; }
  window.addEventListener('load', render);
  render();
}
void initInspector();
